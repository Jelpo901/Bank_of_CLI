Bank_of_CLI is a banking application that operates inside a terminal.
It utilizes core and advanced Java concepts and dev tools, such as Maven and PostgreSQL.
PostgreSQL is the database, Maven allows development with easy access to dependencies to manage multiple layers in the application, such as this application's api, domain, persistence, service, and util. 
Users are allowed to
* Create Account
* Log In
* Deposit
* Withdraw
* Transfer
* View Transaction History
Developers also have the privelege to view system logs and test functions inside the Test folder.
